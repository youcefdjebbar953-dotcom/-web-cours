أساسيات برمجة وتصميم المواقع

تعلم كيفية بناء صفحات ويب حديثة ومتكاملة باستخدام اللغات الأساسية الثلاث

لغة HTML (هيكل الموقع)

هي الهيكل العظمي لأي صفحة ويب وتُستخدم لإضافة النصوص، الصور، والروابط.

العناصر الأساسية

تعتمد HTML على "العناوين" (Tags) مثل <h1> للعناوين و <p> للفقرات النصية.

الوسائط والروابط

تستخدم <a> لربط الصفحات و <img> لعرض الصور وسائط الميديا المختلفة.

index.html 
<!DOCTYPE html>
<html lang="ar">
<head>
    <title>صفحتي الأولى</title>
</head>
<body>
    <h1>مرحباً بك في موقعي</h1>
    <p>هذه بداية رحلتي في تعلم البرمجة!</p>
</body>
</html>

لغة CSS (تنسيق الموقع)

تُستخدم لتنسيق وإضافة الألوان، الخطوط، والمؤثرات البصرية للـ HTML.

الألوان والتنسيق

يمكنك تغيير لون النصوص والتصميم الداخلي والخارجي للمكونات باستخدام Margins و Padding.

التخطيط (Flexbox & Grid)

أنظمة حديثة تتيح لك ترتيب المكونات وتوزيعها بشكل متناسق ومتجاوب مع الهاتف.

style.css 
body {
    background-color: #f8fafc;
    font-family: 'Arial', sans-serif;
}

h1 {
    color: #0284c7;
    text-align: center;
}

لغة JavaScript (التفاعلية)

تمنح الموقع الحياة والتفاعلية مثل فتح القوائم، إرسال البيانات، واستجابة النقرات.

المتغيرات والدوال

تخزين البيانات والتحكم في سير البرنامج من خلال الدوال (Functions) والأحداث (Events).

التحكم بالعناصر (DOM)

تمكنك من تعديل نصوص وصفحات HTML وتغيير تنسيقات CSS ديناميكياً أثناء استخدام الزائر للموقع.

script.js 
// التفاعل عند الضغط على زر
document.querySelector('button').addEventListener('click', function() {
    alert('أهلاً بك! تم النقر على الزر بنجاح.');
});
